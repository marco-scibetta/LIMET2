description: Avvia la dashboard LIMET (build se serve + server API/UI su :8787)
---

Avvia la dashboard LIMET eseguendo `python dashboard/run.py` **in background** (Bash tool con
`run_in_background: true`), poi riferisci all'utente:

> Dashboard avviata → http://127.0.0.1:8787

Se la porta 8787 è già in uso (dashboard già attiva), non riavviarla: rispondi solo
"Dashboard già attiva su http://127.0.0.1:8787".
