LIMET setup guide · 2.0
Setup

Launch the dashboard and prepare the infrastructure

A linear sequence to set up LIMET: plugin, dashboard, Qdrant, Ollama, Postgres and per-project configuration.

1 · Launch the dashboard

1

From the plugin root, launch the dashboard (it builds the frontend if needed and serves API + UI in a single process).

python dashboard/run.py

The script starts the server and opens the browser on http://127.0.0.1:8787. To stop it, close the terminal (Ctrl+C).

2 · Infrastructure

Three optional services, one per LIMET column.

■ Qdrant documents

Vector store for semantic search over documents.

Docker

docker run -d -p 6333:6333 qdrant/qdrant

Local (without Docker)

# native binary from Qdrant's GitHub releases
# (qdrant-x86_64-pc-windows-msvc.zip) → extract and run
qdrant.exe   # listens on :6333

■ Ollama embedding

Generates local embeddings. Already local by nature, no Docker.

ollama pull nomic-embed-text

■ Postgres database

Read-only database queryable via the db MCP.

Docker

docker run -d --name limet-postgres \
  -e POSTGRES_USER=limet \
  -e POSTGRES_PASSWORD=limet_dev \
  -e POSTGRES_DB=limet \
  -p 5432:5432 postgres:18-alpine3.23

Local (without Docker)

# Windows: install and create the service
winget install PostgreSQL.PostgreSQL.18
# then create the role and database
psql -U postgres -c "CREATE USER limet PASSWORD 'limet_dev';"
psql -U postgres -c "CREATE DATABASE limet OWNER limet;"

3 · Per-project configuration

LIMET configures services per project, in two files:

config.yaml committed

Shared defaults, no secrets.

Example — replace with your values

projects:
  my-app:
    qdrant:
      url: http://localhost:6333
    ollama:
      url: http://localhost:11434
      model: nomic-embed-text
    db:
      host: localhost
      port: 5432
      database: mydb
      user: myuser

config.local.yaml gitignored

Overrides and secrets, never in the repo.

projects:
  my-app:
    db:
      password: "••••"

A shared loader (config/loader.py) merges config.local.yaml over config.yaml.

4 · Setup page in the dashboard

1

Open the dashboard and go to Setup.

2

Select the project from the combo — it loads its configuration.

3

Fill in the Qdrant, Ollama and Database sections.

4

Save (writes to config.local.yaml) and press Test DB connection to verify.

Remember: the password is never shown in the dashboard — the field is masked and the value lives only in config.local.yaml.
