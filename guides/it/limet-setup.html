LIMET setup guide · 2.0
Setup

Avvia la dashboard e prepara l'infrastruttura

Una sequenza lineare per mettere in piedi LIMET: plugin, dashboard, Qdrant, Ollama, Postgres e configurazione per progetto.

1 · Avvia la dashboard

1

Dalla root del plugin, lancia la dashboard (builda il frontend se serve e serve API + UI su un solo processo).

python dashboard/run.py

Lo script avvia il server e apre il browser su http://127.0.0.1:8787. Per fermarla, chiudi il terminale (Ctrl+C).

2 · Infrastruttura

Tre servizi opzionali, uno per colonna di LIMET.

■ Qdrant documenti

Vector store per la ricerca semantica sui documenti.

Docker

docker run -d -p 6333:6333 qdrant/qdrant

Locale (senza Docker)

# binario nativo dalle release GitHub di Qdrant
# (qdrant-x86_64-pc-windows-msvc.zip) → estrai e avvia
qdrant.exe   # ascolta su :6333

■ Ollama embedding

Genera gli embedding locali. Già locale per natura, nessun Docker.

ollama pull nomic-embed-text

■ Postgres database

Database read-only interrogabile via MCP db.

Docker

docker run -d --name limet-postgres \
  -e POSTGRES_USER=limet \
  -e POSTGRES_PASSWORD=limet_dev \
  -e POSTGRES_DB=limet \
  -p 5432:5432 postgres:18-alpine3.23

Locale (senza Docker)

# Windows: installa e crea il servizio
winget install PostgreSQL.PostgreSQL.18
# poi crea ruolo e database
psql -U postgres -c "CREATE USER limet PASSWORD 'limet_dev';"
psql -U postgres -c "CREATE DATABASE limet OWNER limet;"

3 · Configurazione per progetto

LIMET configura i servizi per progetto, in due file:

config.yaml committed

Default condivisi, nessun segreto.

Esempio — sostituisci con i tuoi valori

projects:
  my-app:
    qdrant:
      url: http://localhost:6333
    ollama:
      url: http://localhost:11434
      model: nomic-embed-text
    db:
      host: localhost
      port: 5432
      database: mydb
      user: myuser

config.local.yaml gitignored

Override e segreti, mai nel repo.

projects:
  my-app:
    db:
      password: "••••"

Un loader condiviso (config/loader.py) fa il merge di config.local.yaml sopra config.yaml.

4 · Pagina Setup nella dashboard

1

Apri la dashboard e vai su Setup.

2

Seleziona il progetto dalla combo — carica la sua configurazione.

3

Compila le sezioni Qdrant, Ollama e Database.

4

Salva (scrive in config.local.yaml) e premi Test connessione DB per verificare.

Ricorda: la password non viene mai mostrata nella dashboard — il campo è mascherato e il valore vive solo in config.local.yaml.
